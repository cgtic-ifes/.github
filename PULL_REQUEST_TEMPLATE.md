## 🔧 Tipo de Mudança

Marque a opção que melhor descreve sua contribuição (considerando o padrão **[SemVer](https://semver.org/)**):

- [ ] 🐛 **Correção de bug (`PATCH`):** ajuste que corrige uma falha sem quebrar compatibilidade.
- [ ] ✨ **Nova funcionalidade (`MINOR`):** adição de recurso mantendo compatibilidade com versões anteriores.
- [ ] 💥 **Mudança incompatível (`MAJOR`):** alteração que quebra compatibilidade com versões anteriores (detalhe os impactos abaixo).
- [ ] 📚 **Documentação / Refatoração:** melhorias no `README.md`, comentários ou organização interna sem alterar comportamento.
- [ ] 🔒 **Segurança:** correção de vulnerabilidade ou melhoria nas esteiras de CI/segurança.

## ✅ Checklist antes da Revisão

- [ ] Li o `README.md` (e o `CONTRIBUTING.md`, se existir) deste repositório para seguir as diretrizes da instituição mantenedora.
- [ ] Meu código segue os padrões de estilo e estrutura adotados neste projeto.
- [ ] Executei os testes localmente e/ou verifiquei que a esteira de CI (*GitHub Actions*) passou sem erros.
- [ ] Garanti que **nenhuma credencial, senha, token, chave privada ou dado sensível** institucional foi incluído nos commits.
- [ ] Atualizei a documentação pertinente (ex.: `README.md`, variáveis de ambiente, exemplos) caso a mudança exija.
